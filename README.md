# usage
### if you are on windows you have to run docker desktop on your system
### if you are on linux your fine

### build this docker file with this command
> docker build -t hello-name .
### run it with this
> docker run hello-name
your going to see Hello, Captain! in your cli

### if you want to see a custom name
> docker run hello-name X
your going to see Hello, X!
